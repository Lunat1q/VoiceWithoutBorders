# Architecture — Structure and Data Flow

Feature-sliced. `Features/` = user-facing slices, `Infrastructure/` = OS and network adapters. One type per file.

## App (`VoiceWithoutBorders/`)

```
VoiceWithoutBorders/
├── App.xaml(.cs)                 # Composition root: host, MainWindow, overlay, tray, hotkeys; disposes host on exit;
│                                 #   single instance (named event, a second launch shows the first), resume → view model,
│                                 #   --autostart (Run key) starts in the tray and auto-connects
│                                 #   (ShutdownMode=OnMainWindowClose so the hidden overlay never keeps the app alive)
├── Assets/                       # app.ico (exe + window icon), app.png (README); generated by tools/make_icon.py
├── Extensions/
│   └── ServiceCollectionExtensions.cs   # AddSettings, AddAudio, AddNetworking, AddStreaming, AddUi
├── Models/
│   └── StreamKind.cs             # Microphone | SystemAudio (byte on the wire)
├── Features/
│   ├── Hotkeys/                  # HotkeyBinding (record, key-press parsing, display), HotkeyBox (capture control),
│   │                             #   HotkeyController (re-registers on change, reports conflicts in HotkeyStatus)
│   ├── Main/                     # MainWindow.xaml(.cs) (tab shell; minimize → tray), MainStyles.xaml (shared styles),
│   │                             #   Tabs/ StreamTab, ConnectionTab, DevicesTab, HotkeysTab (one UserControl per tab),
│   │                             #   MainViewModel (commands, device pickers, autosave, status/stats) +
│   │                             #   MainViewModel.LiveControls (stream toggles, overlay lock/position, hotkey bindings),
│   │                             #   MainViewModel.Link (connection state, activity lights, latency, skip warning, restart on reconnect/resume),
│   │                             #   MainViewModel.Startup (start with Windows, auto-connect with retries)
│   ├── Overlay/                  # OverlayWindow (topmost pill; click-through when locked, draggable when unlocked;
│   │                             #   ticks on CompositionTarget.Rendering), OverlayViewModel + StreamIndicator (pure)
│   ├── Settings/                 # AppSettings (record + Validate), ISettingsStore, JsonSettingsStore (DPAPI key),
│   │                             #   SharedKeyGenerator
│   ├── Streaming/                # IStreamingService, StreamingService (wires captures/players to the transport,
│   │                             #   per-stream enable, peak levels for the overlay), LinkMonitor (link health), StreamLatency + LatencyHealth (end-to-end estimate)
│   └── Tray/                     # TrayIcon (WinForms NotifyIcon + context menu; the only WinForms use)
└── Infrastructure/
    ├── Audio/                    # AudioDevice, IAudioDeviceService/AudioDeviceService (enumeration),
    │                             #   IAudioEndpointFactory/WasapiEndpointFactory, IAudioCapture/WasapiAudioCapture,
    │                             #   IAudioPlayer/WasapiAudioPlayer, LatencyCappedBuffer (jitter buffer),
    │                             #   WireFormat (48k/16/2, 5 ms chunks, chunking + resampling helpers)
    ├── Interop/                  # NativeMethods (user32), IGlobalHotkeys/GlobalHotkeys (RegisterHotKey on the main window),
    │                             #   IStartupRegistration/RunKeyStartupRegistration (HKCU Run entry)
    └── Network/                  # IPeerTransport/UdpPeerTransport (dual-stack socket, receive loop, stats),
                                  #   PacketCodec (framing, AES-GCM, key derivation, replay window), PacketType,
                                  #   HeartbeatPayload + RoundTripClock (NTP-style round trip, no clock sync)
```

## Tests (`VoiceWithoutBorders.Tests/`)

Mirrors the app tree: `Features/{Hotkeys,Main,Overlay,Settings,Streaming}`, `Infrastructure/{Audio,Network}`, `Extensions/`.
Windows, tray icon and hotkeys are thin Win32/WPF glue and are not unit-tested; their logic lives in view models.

## Data flow

```
Sender                                                     Receiver
──────                                                     ────────
WasapiRecorder (mic, or loopback of an output device)
  │  Windows converts to 48 kHz / 16-bit / stereo
  ▼
WasapiAudioCapture ──960-byte chunks──► StreamingService
                                          │ Send(kind, chunk)
                                          ▼
                                     UdpPeerTransport
                                          │ PacketCodec.Encode (AES-GCM)
                                          ▼
                                   UDP :15300 ───────────►  UdpPeerTransport receive loop
                                                              │ PacketCodec.TryDecode
                                                              ▼
                                                            StreamingService.OnAudioReceived
                                                              │ player for that StreamKind
                                                              ▼
                                                            WasapiAudioPlayer
                                                              │ LatencyCappedBuffer → resample to device rate
                                                              ▼
                                                            WasapiPlayer (headset, or virtual cable input)
```

Alongside audio, each transport sends an empty `Heartbeat` packet every second from Open. The receive loop stamps
the time of every authentic packet (`TransportStats.SincePeer`); `LinkMonitor` turns that and the counters into
Connected / Waiting / KeyMismatch plus Sending / Receiving, sampled once a second by the view model. Sending first
also makes Windows Firewall treat the peer's traffic as replies, so a missing inbound rule does not block audio.

## Packet layout (v2)

| Offset | Size | Field | Notes |
|-------:|-----:|-------|-------|
| 0 | 1 | version | `2` (v1 had no heartbeat; mixed versions reject each other) |
| 1 | 1 | type | `PacketType`: 0 mic, 1 system audio, 2 heartbeat |
| 2 | 4 | session | random per codec, big-endian |
| 6 | 4 | sequence | per type, big-endian |
| 10 | 12 | nonce | random |
| 22 | 16 | tag | AES-GCM tag |
| 38 | n | ciphertext | PCM, n ≤ 960; heartbeat: 24 bytes `SentAt`, `EchoOf`, `HeldFor` (µs) |

Bytes 0–9 are the AES-GCM associated data, so the header is authenticated too.

## Threads

| Thread | Work |
|--------|------|
| UI | View model, start/stop, device enumeration |
| Capture (one per active capture, NAudio) | Chunk + encrypt + `SendTo` |
| Receive loop (thread pool) | Decrypt + write to jitter buffer, stamp peer last-seen |
| Heartbeat loop (thread pool, `PeriodicTimer`) | One empty packet per second |
| Playback (one per active player, NAudio) | Read jitter buffer into the device |
